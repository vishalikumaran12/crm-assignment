# MERN CRM Application

A Customer Relationship Management (CRM) application built using MongoDB, Express.js, React.js and Node.js.

## Features
- User registration and login
- Password hashing and JWT authentication
- Add, view, update and delete customers
- MongoDB Atlas database integration
- React frontend with Tailwind CSS
- Input validation and error handling

## Technologies
- MongoDB Atlas
- Express.js
- React.js and Vite
- Node.js
- Mongoose
- Axios
- Tailwind CSS

## Setup

### Backend
1. Open the `server` folder.
2. Run `npm install`.
3. Create a `.env` file with `PORT`, `MONGO_URI` and `JWT_SECRET`.
4. Run `npm run dev`.

### Frontend
1. Open the `client` folder in a separate terminal.
2. Run `npm install`.
3. Run `npm run dev`.

## Security
Do not commit environment variables or database credentials.
